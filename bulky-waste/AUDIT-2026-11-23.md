# 전수 검수 기록 (2026-11-23)

발단: 과천 '베드범퍼'가 가로 1m 이상 3,000원 한 줄만 나오고 1m 미만 2,000원이 빠짐. 원칙: 규격이 여럿이면 전부 보여 주고 고객이 고른다.

## 방법
- 로컬 DB에 운영과 같은 131곳(공공데이터 82곳 23,186행 + 수집표 49곳 + 과천 확정표)을 채움. 운영자가 어드민에서 넣은 확정표·표현 사전은 빠져 있음.
- 검수 4갈래: 규격 누락 전수(A), 생활 품목 195개 × 131곳(B), 데이터 품질(C), 연결 규칙·고객 화면(D).
- 고치기 전·후 비교: 221개 검색어 × 131곳 = 28,951개 답변을 떠서 바뀐 답을 전부 대조.

## 남은 데이터 오류 (조례 원문 확인 후 재수집 필요)

- 설명문이 품목으로 들어감: 논산 "※ 상기 품목 외…" 7행, 남동 "기타100 100,000", 용산 "추가금 30,000", 중랑 "(화이트보드)".
- 오타: 부산 남구 "폭 85m 이상~110cm 미만", 영등포 "지름 지름". 재질 구분 유실: 오산·부산 서구 식탁, 의왕 책상·침대·운동기구, 시흥 수족관.

## 사람 판단이 필요한 것
1. 범퍼침대(바닥형 유아 침대)를 조례에 따로 없을 때 무엇으로 안내할지(지금: 범퍼침대 → 유아용 침대 → 놀이매트, 없으면 침대 규격 전체).
2. 침대범퍼 대체 순서: 놀이매트(면적 단가가 많음) / 쿠션 / 방석 / 이불.
3. 유사품목 사전의 논쟁적 연결: 캣타워·사물함 → 신발장, 개집 → 고무통, 하이체어·쏘서·점퍼루·바운서 → 보행기, 화이트보드·칠판 → 간판, 커튼 → 이불, 유아매트 → 옥매트.
4. 조례 원문에 금지어 정규식이 걸리는 경우('유사 매트리스', '유사한 품목이 없는', '석유사용'): 원문 그대로 둘지, 표시명으로 바꿀지.
5. 경기 광주 전기그릴: 1M 이상이 무상수거, 1M 이하가 2,000원 — 뒤집혔는지 원문 확인.
6. 무상수거와 유료 줄을 함께 보일 때 "무상수거가 안 될 때만 이 금액" 문구를 붙일지.
7. 과천 '쿠션' 단독 검색을 '유아용 쿠션' 금액으로 받을지, '자동차 범퍼'를 받을지.
8. 과천 확정표 전기장판(전기매트·전기담요)에 2인용 이상 5,000 줄이 없음(조례에는 있음).

## 아직 못 고친 로직
- 브랜드가 붙은 이름(삼성냉장고, LG 세탁기, 시몬스 매트리스)은 늘 확인 질문으로 감.
- 조례 규격 칸에 적힌 하위 품목(의자 │ 안마의자)을 앞말 없이 직접 찾지는 못함(앞말이 있을 때만 규격 일치).
- 옷장 → 장롱, 좌탁 → 상, 어항 → 수족관 같은 다른 이름 연결은 확인 후 안내로 남음.
- 끝말 품목에 다른 하위 품목이 섞여 있으면(침대 │ 돌침대 세트) 전부 펼쳐 보임.
- 과천 확정표 수식어가 검색어가 되는 문제(모니터 → 모니터 거치대 등)는 과천 확정표 정리와 함께 처리 필요.
